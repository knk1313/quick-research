# quick-research

「〇〇ってなんだっけ」のような軽い知識の質問に、毎回同じ形と深さで答えるClaude Codeのスキルです。答えに出てくる数字・年・固有名詞は、取ってきた出典の本文と機械で照合してから返します。

軽く聞いただけなのに答えが長い散文になる、答えの深さが毎回ばらつく、どこまで信じてよいか分からない、という負担を減らすためのスキルです。

## 何をするか

- 答えを「一言（事実で書く）、要点、例、注意、出典、次に聞けること」の形で返す。深さは「一言で」「詳しく」で3段階に変えられる
- 検索は3回、読むページは4件までに抑える。足りなければ、deep-researchで調べ直すかを聞く
- ページの本文の抽出と、質問に関係する段落の選び出しはスクリプトで行い、Claudeが読む量を減らす
- 答えの中の年、数値、書名、固有名詞が、出典の本文にあるかを照合する。見つからないものは「（未確認）」と書くか、削る
- 出典ごとに、日付、書き手、参考文献の有無、ほかの出典との一致を手がかりにして、○△×の記号を付ける

手元のファイルやコードについての質問と、複数の観点を比べる報告書づくりには使いません。前者はスキルなしで十分に答えられ、後者はdeep-researchの役割です。

## 動作環境

| 環境 | 必要なもの | ページの読み方 |
| --- | --- | --- |
| Claude Code | WebSearch、[uv](https://docs.astral.sh/uv/)（スクリプトの依存パッケージを初回に自動で入れる） | スクリプトでページを取り、質問に関係する段落だけをClaudeに渡す |
| Claudeアプリ（claude.ai、デスクトップ） | コード実行とWeb検索を有効にした、Pro以上のプラン | Web検索の機能でページを読み、根拠の段落を保存してから照合する |

どちらの環境でも、答えの形と、出典との照合は同じです。Claudeアプリでは、関係する段落だけを選んでClaudeが読む量を減らす処理は使えません。

## 使い方

### Claude Code

```text
/plugin marketplace add knk1313/quick-research
/plugin install quick-research@quick-research
```

### Claudeアプリ

1. [Releases](https://github.com/knk1313/quick-research/releases)から`quick-research.zip`を取る。手元で作るときは`bash scripts/build-zip.sh`を実行する（`dist/quick-research.zip`ができる）
2. Claudeアプリの設定の、スキルの画面から、zipをアップロードする

### 質問する

入れたら、普段どおりに質問します。

```text
HTTPとHTTPSの違いってなんだっけ
```
